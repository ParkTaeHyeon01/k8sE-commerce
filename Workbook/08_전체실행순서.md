# 08. 전체 실행 순서

처음 환경을 세팅하고 서비스를 올리는 순서.

## Step 1. 인프라 시작

각각 별도 터미널에서 실행.

```powershell
# Kafka
C:\kafka\bin\windows\kafka-server-start.bat C:\kafka\config\kraft\server.properties
```

```bash
# MongoDB (WSL2 터미널)
sudo systemctl start mongod
```

```powershell
# Redis
redis-server
```

```powershell
# MariaDB (Windows 서비스)
Start-Service -Name "MariaDB"
```

## Step 2. 환경변수 설정

```powershell
# 루트 .env 없으면 생성
cp .env.example .env
```

## Step 3. Kafka Consumer 시작

```powershell
cd Kafka
python main.py
```

## Step 4. 카테고리 수집 (최초 1회)

```powershell
cd Crawler
python category_crawler.py
```

## Step 5. 상품 크롤링 (최초 1회 — 오래 걸림)

별도 터미널 2개에서 동시 실행:

```powershell
# 터미널 1
cd Crawler
$env:CRAWL_TARGET="best"
python main.py
```

```powershell
# 터미널 2
cd Crawler
$env:CRAWL_TARGET="sales"
python main.py
```

## Step 6. 순위 업데이트 (크롤링 완료 후)

```powershell
cd Crawler
$env:CRAWL_TARGET="best"
python rank_updater.py

$env:CRAWL_TARGET="sales"
python rank_updater.py
```

## Step 7. 백엔드 서버 시작

```powershell
# 터미널 1: Product gRPC 서버
cd Backend/product
python main.py
```

```powershell
# 터미널 2: Gateway
cd Backend/gateway
python -m uvicorn main:app --port 8000
```

## Step 8. 프론트엔드 시작

```powershell
cd Frontend
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

---

## 이미 데이터가 있는 경우 (재시작)

인프라 + 백엔드 + 프론트만 올리면 됨:

```
1. Kafka / MongoDB / Redis / MariaDB 시작
2. Backend/product  → python main.py
3. Backend/gateway  → python -m uvicorn main:app --port 8000
4. Kafka/           → python main.py  (신규 크롤링 수신 대기)
5. Frontend/        → npm run dev
```
